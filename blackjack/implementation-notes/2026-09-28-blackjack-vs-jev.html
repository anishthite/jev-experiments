API contract

POST /api/games { wager?: number, bankroll?: number }
GET /api/games/:id
POST /api/games/:id/actions { action: "hit" | "stand" | "double" }

Game → { id, status, bankroll, wager, player, dealer, result, allowedActions }

Algorithm

  1. Deal alternating cards; expose one dealer card while play is active.
  2. Score aces as 11, then reduce by 10
  3. Resolve naturals before input; on stand or double, dealer hits below 17.
  4. Apply payout to bankroll once and return terminal state.

UI layout

  1. Header: brand, bankroll, live indicator.
  2. Table: Jev portrait, dealer hand, centered status, player hand.
  3. Controls: wager setup then hit, stand, and double actions.
