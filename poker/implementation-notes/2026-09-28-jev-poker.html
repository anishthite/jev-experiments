API contract

GET /api/games/:id

POST /api/games/:id/next-hand { revision }

Algorithm

  1. Post alternating heads-up blinds; button acts first preflop.
  2. Validate server-derived legal actions and optimistic revision.
  3. Advance streets after equal contributions and both actions.
  4. Evaluate every five-card subset of seven cards; compare lexicographic rank vectors.
  5. Run Jev until control returns to the human or the hand completes.

Decisions

D-004Hide Jev’s cards until showdown. API cannot leak private information.
