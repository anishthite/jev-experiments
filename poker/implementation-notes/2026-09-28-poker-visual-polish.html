Decisions

D-101Animate via the CSS `translate` property, not `transform`, so the fanned hero-card rotation (D-008) is preserved. Modern browsers only (Safari 14.1+).
D-102Whole board re-deals on each new street rather than animating only the new card(s). Reads as a fresh deal; finer diffing not worth the code.

Tradeoffs

T-101Hand-name pills hidden on ≤380px / short viewports over squeezing them in. Chosen: no overflow risk. Rejected: responsive repositioning — cramped layouts have no free space beside cards.
T-102No chip-stack graphic beside the pot (considered). Pill + bump pulse carries the feedback; skip until someone asks.
